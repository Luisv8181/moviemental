# Contributing to Moviemental

Read docs/PROJECT_MODEL.md and the evidence and ethics policies before submitting entries.

## Rules
1. Use stable IDs and existing schemas.
2. Separate explicit statements from interpretation.
3. Cite sources for diagnoses and important factual claims.
4. Prefer experiential tags when a diagnosis is not established.
5. Include proportionate content warnings when supported by the work.
6. Do not reproduce scripts, substantial dialogue, copyrighted posters, or large external datasets.
7. Use respectful, non-stigmatizing language.
8. Document uncertainty and credible disagreement.
9. Do not mark a new entry reviewed unless the review is documented.

## Workflow
Propose major taxonomy or schema changes in an issue. Add or update a JSON record, validate IDs and references, include evidence for key claims, then open a pull request.
